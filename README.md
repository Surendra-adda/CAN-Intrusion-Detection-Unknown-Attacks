# Unknown-Attack Detection in In-Vehicle CAN Networks

This repository contains the implementation scripts, selected experiment summaries, and figures associated with the student research paper.

## Repository structure

```text
.
├── src/                 # preprocessing, training, evaluation, analysis scripts
├── results/             # selected CSV summaries and result figures
├── paper/               # LaTeX paper source, bibliography, and paper figures
├── requirements.txt
├── README.md
└── .gitignore
```

## Implemented workflow

1. `src/preprocess_can.py` prepares the processed training, calibration, and unknown-test CSV files from the dataset capture files.
2. `src/train_track_a.py` trains the original-feature Isolation Forest baseline.
3. `src/train_track_b.py` trains the known-class neural classifier and energy-based OOD baseline.
4. `src/diagnose_track_b_embeddings.py` extracts the neural hidden representation and evaluates a benign-only Isolation Forest.
5. `src/calibrate_embedding_threshold.py` selects a 97.5th-percentile threshold using benign calibration scores.
6. `src/evaluate_calibrated_threshold.py` evaluates the fixed threshold on the unknown-test predictions.
7. `src/analyze_embedding_thresholds.py`, `src/analyze_attack_score_distributions.py`, and `src/analyze_attack_features.py` perform additional diagnostic analyses.
8. `src/fedgan_max_train_energy.py` evaluates a maximum-known-malicious-training-energy threshold adaptation using the saved Track B model and scaler.

Run commands from the repository root. The scripts resolve their data and result folders relative to the repository root.

## Dataset and generated data

The raw CAN-train-and-test v1.5 capture files are not included. Obtain the dataset from its official repository and place the required capture files under `set_01/` according to the dataset's instructions. Then run:

```bash
python src/preprocess_can.py
```

The preprocessing script generates `processed_data/`. That folder is intentionally excluded from Git because it contains large derived data. Training and evaluation scripts expect `processed_data/train.csv`, `processed_data/calibration.csv`, and `processed_data/unknown_test.csv`.

Some later scripts also expect model/scaler artifacts generated by the training scripts under `results/`. The `.pth` and `.joblib` artifacts are excluded from Git; regenerate them by running the corresponding training scripts.

## Important research scope

This is an MLP hidden-representation + benign-only Isolation Forest study inspired by the unknown-attack detection problem in FedGAN-ID. It is **not a full FedGAN-ID reproduction**: this code does not implement GAN training, federated aggregation, differential privacy, MTF, READ, or CAN message graph construction.

The paper reports the 99th-percentile embedding operating point (F1 23.47%) as the primary preselected result. The 97.5th-percentile result (F1 49.37%) is retained as exploratory because the unknown-test set had been inspected during earlier threshold exploration. It must not be described as an independently validated improvement.

The public CAN dataset evaluation is not directly comparable with FedGAN-ID's private XPeng dataset and protocol. Do not claim direct superiority from these results.

## Included files and reproducibility limitations

This archive contains the source scripts and selected CSV/PNG summaries available for this project. It does not include raw datasets, processed CSVs, trained model checkpoints, or scaler files. Consequently, running the complete workflow requires downloading the dataset and regenerating intermediate data and model artifacts.

Check the README and dataset licence before redistributing any dataset material. No open-source licence is assigned in this repository; ask the project guide before adding one.
