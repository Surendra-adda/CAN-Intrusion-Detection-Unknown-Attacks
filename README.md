# Unknown-Attack Detection in In-Vehicle CAN Networks

This repository contains the code, selected experiment outputs, and the revised research manuscript for an empirical study of unknown-attack detection in Controller Area Network (CAN) traffic.

## Repository structure

```text
.
├── src/                 # preprocessing, training, evaluation, and analysis scripts
├── results/             # selected CSV summaries and diagnostic figures
├── paper/
│   ├── main.tex         # IEEEtran manuscript source
│   ├── references.bib   # BibTeX references cited by main.tex
│   ├── images/          # figures referenced by the manuscript
│   ├── README.md        # manuscript build instructions and scope notes
│   └── research_paper_12pages.pdf
├── requirements.txt
├── README.md
└── .gitignore
```

## Implemented workflow

1. `src/preprocess_can.py` prepares the processed training, calibration, and unknown-test CSV files from the dataset capture files.
2. `src/train_track_a.py` trains the original-feature Isolation Forest baseline.
3. `src/train_track_b.py` trains the known-class neural classifier and energy-based OOD baseline.
4. `src/diagnose_track_b_embeddings.py` extracts the neural hidden representation and evaluates a benign-only Isolation Forest.
5. `src/calibrate_embedding_threshold.py` computes the 97.5th-percentile threshold from benign calibration scores. This operating point is exploratory in the manuscript because the unknown-test file had already been inspected during earlier threshold exploration.
6. `src/evaluate_calibrated_threshold.py` evaluates the corresponding saved predictions and threshold.
7. `src/analyze_embedding_thresholds.py`, `src/analyze_attack_score_distributions.py`, and `src/analyze_attack_features.py` perform additional diagnostic analyses.
8. `src/fedgan_max_train_energy.py` evaluates a maximum-known-malicious-training-energy threshold adaptation using the saved Track B model and scaler.

Run commands from the repository root. The scripts are intended to resolve data and result folders relative to the repository root.

## Setup

Create and activate a Python virtual environment, then install dependencies:

```bash
python -m venv .venv

# Windows PowerShell
.venv\\Scripts\\Activate.ps1

# macOS/Linux
# source .venv/bin/activate

pip install -r requirements.txt
```

The requirements file lists package names but is not a fully pinned environment lockfile. Exact package versions were not preserved in this project archive.

## Dataset and generated files

The raw CAN-train-and-test v1.5 capture files are not included. Obtain the dataset from its maintainers and place the required capture files under `set_01/` in accordance with the dataset's instructions. Then run:

```bash
python src/preprocess_can.py
```

The preprocessing script generates `processed_data/`. That folder is intentionally excluded from Git because it contains derived data. Training and evaluation scripts expect `processed_data/train.csv`, `processed_data/calibration.csv`, and `processed_data/unknown_test.csv`.

Some later scripts expect model and scaler artifacts generated by earlier training scripts under `results/`. The `.pth` and `.joblib` artifacts are excluded from Git; regenerate them by running the corresponding training scripts.

## Main reported result

The revised manuscript identifies the embedding-based Isolation Forest at the 99th percentile of benign calibration scores as the primary operating point:

- Precision: 30.68%
- Recall: 19.00%
- F1-score: 23.47%
- False-positive rate: 1.04%
- ROC-AUC: 0.9423
- PR-AUC: 0.4299

The 97.5th-percentile result (F1-score 49.37%, recall 62.53%) is retained as exploratory, not as an independently validated improvement, because the same unknown-test file had been examined during earlier threshold exploration. Refer to `paper/main.tex` for the experimental detail, confusion matrices, and family-wise results.

## Research scope and limitations

This is an MLP hidden-representation plus benign-only Isolation Forest study inspired by the unknown-attack detection problem in FedGAN-ID. It is **not a full FedGAN-ID reproduction**. This implementation does not include GAN training, federated aggregation, differential privacy, MTF, READ, or CAN message-graph construction.

The public CAN dataset and its attack taxonomy differ from the private XPeng dataset used in FedGAN-ID. The results are therefore not a direct numerical comparison with that paper. The unknown-test file was inspected during exploratory analysis, benign subsampling affects the class prevalence, and the reported experiment does not include repeated-seed confidence intervals. These limitations are disclosed in the manuscript.

## Reproducibility notes

This repository includes source scripts and selected CSV/PNG result summaries, but not raw dataset captures, processed CSV files, trained model checkpoints, or scaler artifacts. A complete rerun requires obtaining the dataset and regenerating these intermediate files. A successful LaTeX build or Python syntax check should not be interpreted as proof that the complete experiment has been independently reproduced.
